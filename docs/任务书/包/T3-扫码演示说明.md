# T3 · C 端 uni-app（扫码演示说明）

> 一页纸，答辩现场照着点就行。

## 1. 起服务（2 条命令）

```powershell
# H5：http://localhost:5183
cd D:\AAA\hotel-management-yudao\yudao-ui\yudao-ui-hotel-app
$env:NODE_OPTIONS=""
npm run dev:h5

# 小程序：产物在 dist/build/mp-weixin
npm run build:mp-weixin
```

后端未启动也能演示：接口不可用时前端会自动切到本地演示数据，右上角显示「演示数据」。接口好了会自动走真实后端（`src/utils/config.js` 中 `APP_MODE='auto'`，可改 `api` / `mock`）。

## 2. 三种演示姿势

1. **投屏 H5**：Chrome 打开 `http://localhost:5183`，按 F12 切手机尺寸；页面在桌面端会自动收成一列手机画布。
2. **微信开发者工具**：导入 `yudao-ui/yudao-ui-hotel-app/dist/build/mp-weixin`，AppID 选「测试号」（manifest 里是 `touristappid`），勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」。
3. **手机扫码**：开发者工具「预览」生成二维码；真机需把 `src/utils/config.js` 里的小程序 `baseUrl` 改成电脑局域网 IP（如 `http://192.168.1.10:48080/app-api`），并与电脑同一 WiFi。

## 3. 三分钟演示动线

1. 首页选日期（默认今天/明天）→ 看到 4 个房型、价格、「仅剩 x 间」。
2. 点「标准双人间」→ 看轮播、设施、逐日房价、选「含早套餐」→ 立即预订。
3. 填入住人「林晚」、手机 `13800138000` → 提交订单 → 支付页。
4. 点金色「模拟支付成功」（走 `POST /app-api/hotel/pay/mock-success`）→ 支付成功页。
5. 查看订单 → 状态「已确认」→ 点「自助入住」→ 变「已入住」。
6. 订单详情点「申请发票」→ 填抬头提交 → 发票状态「已提交」；再点「自助退房」→ 变「已退房」。

忘记流程时可从「我的订单」重新进入；演示数据存在浏览器本地，刷新不丢单。

## 4. 登录

手机号任意 11 位，验证码固定 `123456`（点「获取验证码」会自动填入）。登录后可看「我的订单」、积分与自助入住/退房。

## 6. 接口与字段

统一走 `/app-api`，请求头带 `tenant-id: 1` 与会员 `Authorization: Bearer <token>`，统一解包 `{code,msg,data}`。

| 用途 | 接口 |
|---|---|
| 可售房型 | `GET /hotel/booking/availability` |
| 占位 / 提交 | `POST /hotel/booking/hold` / `submit` |
| 支付 / 结果 | `POST /hotel/booking/pay`、`GET /hotel/booking/pay-result` |
| 模拟支付 | `POST /hotel/pay/mock-success` |
| 会员 | `POST /hotel/member/login`、`GET /hotel/member/info` |
| 我的订单 | `GET /hotel/booking/my-order/page`、`get`、`PUT cancel` |
| 自助 | `PUT /hotel/member/self-check-in`、`self-check-out` |
| 发票 | `POST /hotel/member/invoice-apply` |

房型展示字段（`cover_image`/`images`/`bed_type`/`breakfast`/`window`）由 `sql/mysql/hotel-t3.sql` 追加，已在本机库执行。
