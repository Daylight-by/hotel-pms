### 2.3 本机环境坑位清单（**已踩过，禁止重复踩**）

| 坑 | 现象 | 解法 |
|---|---|---|
| **LocalDate 序列化成 `[2026,10,21]`** | 芋道全局 `spring.jackson.write-dates-as-timestamps=true` | 所有 RespVO 的 `LocalDate` 字段必须加 `@JsonFormat(pattern = "yyyy-MM-dd", timezone = "GMT+8")` |
| **`Map.of()` 遇 null 键抛 NPE** | 查询出 id→name 映射后 `map.get(null)`（如未指派保洁的 assigneeId）抛异常 → 接口 500 | 一律用 `new HashMap<>()`，空值时用 `Collections.emptyMap()`，**禁止** `Map.of()` |
| **MyBatis-Plus `LambdaQueryWrapperX` 泛型陷阱** | 继承来的 `eq/lt/gt/in` 返回父类型 `LambdaQueryWrapper`，链式再接 `neIfPresent` 编译失败 | 先链式构造基础条件，再用 `if (x != null) wrapper.ne(...)` 单独追加，不要一路链式到底 |
| **后端端口 8857 被占用** | `Port 8857 already in use` | 必须显式 `--server.port=48080` |
| **前端端口 80 被 Steam++ 占用** | vite 起不来 | 必须显式 `--port 5173` |
| **Vite 启动崩溃 `SAFE_DELETE_BULK_CONFIRM_REQUIRED`** | WorkBuddy 通过 `NODE_OPTIONS=--require=...node-language-shim.cjs` 注入钩子 | 用上面的 `env -u NODE_OPTIONS ...` 方式启动 |
| **无符号链接权限** | pnpm 装完 `node_modules` 只有 12 个空 @scope 目录，缺 vite | `pnpm-workspace.yaml` 已设 `nodeLinker: hoisted` + `allowBuilds`，**不要**改回 symlink |
| **批量删除被 safe-delete 拦截** | `rm -rf` / `mv` 报 Permission denied 或 bulk-confirm | 用 PowerShell `Remove-Item -Recurse -Force`；脚本报 `trash-failed` 常是误报，以 `Test-Path` 复核为准 |

### 2.4 芋道编码规范（**必须遵守，验收会查**）

**分层（自上而下）**
```
controller/admin/{模块}/{Xxx}Controller.java          只做参数校验 + 调 service + 包 CommonResult
  └─ controller/admin/{模块}/vo/{Xxx}PageReqVO.java   分页查询入参（继承 PageParam）
     controller/admin/{模块}/vo/{Xxx}SaveReqVO.java   新增/修改入参
     controller/admin/{模块}/vo/{Xxx}RespVO.java      出参
service/{模块}/{Xxx}Service.java                      接口
  └─ service/{模块}/{Xxx}ServiceImpl.java             实现，@Service
dal/dataobject/{模块}/{Xxx}DO.java                    @TableName + extends TenantBaseDO
dal/mysql/{模块}/{Xxx}Mapper.java                     extends BaseMapperX<XxxDO>
enums/{Xxx}Enum.java                                  枚举，值用 10/20/30 递增留间隔
enums/ErrorCodeConstants.java                         错误码，统一在此登记
```

**硬性要求**
1. DO 必须 `extends TenantBaseDO`（自动带 tenant_id / creator / create_time / updater / update_time / deleted）。
2. 建表必须带 `tenant_id bigint NOT NULL DEFAULT 0` 及芋道四件套（`creator`/`create_time`/`updater`/`update_time`）和 `deleted bit(1) DEFAULT b'0'`。
3. Controller 权限注解：`@PreAuthorize("@ss.hasPermission('hotel:{模块}:{动作}')")`，动作 ∈ `query|create|update|delete|export|audit`。
4. 返回统一 `CommonResult<T>`，分页 `CommonResult<PageResult<XxxRespVO>>`。
5. 业务异常必须走 `throw ServiceExceptionUtil.exception(ERROR_CODE_XXX)`，错误码登记在 `ErrorCodeConstants`（hotel 模块号段 `1-003-004-xxx`）。
6. 金额一律 `BigDecimal`，**禁止** double/float；比较用 `compareTo`，不要用 `equals`。
7. 分页/列表查询走 `LambdaQueryWrapperX` 的 `likeIfPresent` / `eqIfPresent` / `betweenIfPresent`。
8. 新增表必须同步在 `sql/mysql/hotel.sql` 追加 `CREATE TABLE`（**保留已有建表语句**，只追加，不要重写整个文件导致丢演示数据）。
9. 新增菜单/权限必须在 `sql/mysql/hotel.sql` 追加 `INSERT INTO system_menu`（hotel 菜单 ID 段 **20000–20199**，P1/P2 可扩到 20200+）。
10. 前端新增页面必须配 `@/api/hotel/{模块}/index.ts` + `@/views/hotel/{模块}/index.vue`，并在后端 `system_menu` 里配 `component` 为 `hotel/{模块}/index`。

> 先读 [`00-总纲与派发说明.md`](./00-总纲与派发说明.md) 第 2 节（环境与规范）与第 4 节（通用 DoD），再动手。

## 0. 为什么是这些

当前系统本质是「单房间 + 一口价 + 一个金额字段」，离真实酒店运营差六块。没有房价日历就没有收益管理和库存；没有账页就记不了杂费、分不了账、对不了账；没有夜审和营业日就不算 PMS（酒店一天的账是以「营业日」为界过账的，不是自然日）；没有续住/换房/钟点房，前台每天都在绕开系统干活；没有交班和发票，收银下班交接全靠纸；没有 ADR/RevPAR/OCC，经营者看不到真实经营状况。

P0 做完 = 一家单店前台可以全靠这个系统开一天门。

### 1.1 改表（ALTER，禁止 DROP COLUMN）

```sql
-- 房型：支持钟点房
ALTER TABLE `hotel_room_type`
    ADD COLUMN `hourly_price` decimal(10,2) NULL COMMENT '钟点房价格（元/时段）' AFTER `base_price`,
    ADD COLUMN `hourly_hours` int NULL DEFAULT 3 COMMENT '钟点房时长（小时）' AFTER `hourly_price`,
    ADD COLUMN `hourly_enabled` bit(1) NOT NULL DEFAULT b'0' COMMENT '是否开放钟点房' AFTER `hourly_hours`,
    ADD COLUMN `deposit` decimal(10,2) NULL DEFAULT 0 COMMENT '建议押金' AFTER `hourly_enabled`;

-- 房间：维修/预留锁定与排序
ALTER TABLE `hotel_room`
    ADD COLUMN `lock_status` tinyint NOT NULL DEFAULT 0 COMMENT '锁定状态：0 正常 1 维修锁定 2 预留锁定' AFTER `status`,
    ADD COLUMN `sort` int NOT NULL DEFAULT 0 COMMENT '排序' AFTER `lock_status`;

-- 订单：营业日、订单类型、押金、人数、关联单
ALTER TABLE `hotel_order`
    ADD COLUMN `room_type_id`  bigint      NULL COMMENT '房型编号（冗余，便于统计）' AFTER `room_id`,
    ADD COLUMN `order_type`    tinyint     NOT NULL DEFAULT 10 COMMENT '订单类型：10 全日房 20 钟点房' AFTER `room_type_id`,
    ADD COLUMN `business_date` date        NULL COMMENT '所属营业日（入账归属日）' AFTER `order_type`,
    ADD COLUMN `deposit`       decimal(10,2) NOT NULL DEFAULT 0 COMMENT '押金' AFTER `amount`,
    ADD COLUMN `adult_count`   int         NULL DEFAULT 1 COMMENT '成人数' AFTER `nights`,
    ADD COLUMN `child_count`   int         NULL DEFAULT 0 COMMENT '儿童数' AFTER `adult_count`,
    ADD COLUMN `parent_order_id` bigint    NULL COMMENT '原订单号（续住/换房时关联）' AFTER `child_count`,
    ADD COLUMN `check_in_time`  datetime   NULL COMMENT '计划入住时间（钟点房精确到时段）' AFTER `check_in_date`,
    ADD COLUMN `check_out_time` datetime   NULL COMMENT '计划离店时间（钟点房精确到时段）' AFTER `check_out_date`,
    ADD KEY `idx_business_date` (`business_date`);

-- 住客：会员/协议单位标记（P1 细化）
ALTER TABLE `hotel_guest`
    ADD COLUMN `guest_level` tinyint NOT NULL DEFAULT 0 COMMENT '客人类别：0 散客 1 会员 2 协议单位 3 中介' AFTER `sex`,
    ADD COLUMN `company`     varchar(100) NULL COMMENT '所属单位' AFTER `guest_level`,
    ADD COLUMN `address`     varchar(200) NULL COMMENT '联系地址' AFTER `company`;
```

## 2. 后端任务

### 2.1 房价日历 `rate`

包：`controller/admin/rate`、`service/rate`、`dal/dataobject/rate`、`dal/mysql/rate`

DO：`RoomDailyRateDO`（`hotel_room_daily_rate`）。字段与建表一致。

**`RateCalendarService`**
```java
// 批量维护：按房型 + 日期区间设置价格/库存/开关，已存在则更新，不存在则插入
Long batchSave(RoomDailyRateSaveReqVO reqVO);          // 权限 hotel:rate:update
// 查询：某房型在某日期区间的日历（缺失日期要返回，price 取房型 base_price，status 默认开房，total_inventory 取 0）
List<RoomDailyRateRespVO> listByRange(Long roomTypeId, LocalDate begin, LocalDate end);
// 可用性校验（下单/续住时调用）：区间内每天都要 开房 且 剩余房量 > 0
void validateAvailable(Long roomTypeId, LocalDate checkIn, LocalDate checkOut, Integer roomCount, Long excludeOrderId);
// 占用/释放（下单成功 sold_inventory+1，取消/退房 -1），必须保证不为负
void occupy(Long roomTypeId, LocalDate date, int count);
void release(Long roomTypeId, LocalDate date, int count);
// 房态盘：返回每房型每天的 价格/总房量/已售/剩余
List<RateCalendarBoardRespVO> getBoard(LocalDate begin, LocalDate end);
```

Controller 路径（权限码）：
| 方法 | 路径 | 权限 |
|---|---|---|
| POST | `/hotel/rate/batch-save` | `hotel:rate:update` |
| GET | `/hotel/rate/list?roomTypeId=&beginDate=&endDate=` | `hotel:rate:query` |
| GET | `/hotel/rate/board?beginDate=&endDate=` | `hotel:rate:query` |
| GET | `/hotel/rate/page` | `hotel:rate:query` |

> **业务规则**
> - `total_inventory` 默认取该房型下的房间总数，允许人工下调（超额预订控制）。
> - 剩余房量 = `total_inventory - sold_inventory`，**不得为负**。
> - `status=20 关房` 时该日期完全不可售（用于装修、长包房占用）。
> - 未维护的日期按房型 `base_price` 兜底，**不报错**（避免前台因漏维护而无法开单）。

### 2.2 账务账页 `folio`

包：`controller/admin/folio`、`service/folio`、`dal/dataobject/folio`、`dal/mysql/folio`

DO：`FolioDO`、`FolioItemDO`、`PaymentRecordDO`。

**`FolioService`**
```java
Long createFolio(FolioCreateReqVO reqVO);                 // 开账页（订单确认时自动开主账页）
FolioRespVO getFolio(Long id);                            // 含 items 明细、余额、收款合计
```

> - `postCharge` 必须校验账页 `status != 30`（已结账）与 `!= 50`（已取消），否则抛 `ERROR_FOLIO_ALREADY_SETTLED`。
> - 冲销只允许对 `direction=1`（消费）的 `status=10` 明细执行；冲销后原明细 `status=20` 且 `void_id` 指向新生成的反向明细。
> - 押金入账用 `item_type=60`，退款用 `item_type=80`（`direction=2`）。
> - 所有明细必须写 `business_date`（取当前营业日，不是 `LocalDate.now()`）。
> - 收款必须同时写 `hotel_payment_record`，并回写订单 `paid_amount` 与 `payment_status`（全付=30，部分=20）。

> **夜审流程（严格按序，单事务）**
> 1. 取当前营业日 D，校验该 D **没有 status=20 的夜审记录**，否则抛 `ERROR_NIGHT_AUDIT_ALREADY_DONE`。
> 2. 校验无「应离未离」异常：存在 `status=30(已入住)` 且 `check_out_date <= D` 的订单 → 抛 `ERROR_NIGHT_AUDIT_NOT_ALLOWED`（提示先处理）。
> 3. 对全部 `status=30 已入住` 的订单**过账当日房费**：取该订单房型在 D 的日历价（无则房型 `base_price`，再无则房间 `price`），写 `hotel_folio_item`（`item_type=10 房费`，`business_date=D`，`direction=1`），重算账页余额。
> 4. 汇总 `room_charge_total` / `posted_room_count` / `posted_item_count`。
> 5. 写 `hotel_night_audit`（`status=20 成功`，`end_time`）。
> 6. 营业日 `D+1` 并写回 `hotel_business_date`，`status` 回 10。
> 7. 任一步异常：事务回滚 + 写一条 `status=30 失败` 记录（记录 `fail_reason`），**营业日不得推进**。
>
> **并发**：用 Redis 分布式锁（key `hotel:night-audit:{tenantId}`）防重复触发。
