## 三、开发期间修复的问题（共 8 处）

1. `GuestDO` 字段为 `guestLevel`（非 level），DemoDataServiceImpl 两处编译错误
2. 前端 3 处：report download 为默认导出（`download.excel`）、dashboard 移除 Echart import（全局组件）、`@/hooks/usePermission` 不存在 → `v-hasPermi` 指令
3. 订单号前缀用 `ORDER_TIME_FMT` 格式化 LocalDate → `UnsupportedTemporalTypeException`（generate/nextOrderSeq 两处改 DATE_FMT）
4. 支付流水号同秒随机碰撞 → `T4+日期+6位递增`，新增 nextTradeSeq()
5. `uk_folio_no` 唯一键不含 deleted，逻辑删行仍占号 → nextFolioSeq/nextOrderSeq/nextTradeSeq 改 JdbcTemplate 原生 SQL 取含已删行的真实最大号
6. clean 需物理删除 hotel_member（uk_member_no 不含 deleted），且会员 level=10（非 1）
7. **演示 folio 前缀改 F9**（P0 业务 folio 号段为 `F+日期`，uk_folio_no 无 deleted 列，逻辑删除的演示 folio 会永久占用号段导致业务开账 DuplicateKeyException —— 曾使 check_baseline「创建订单」失败；F9 前缀彻底隔离，物理清除旧 F 前缀演示 folio 后恢复）
8. 遗留脏数据一次性清除：`sql/mysql/t4-demo-purge.sql`（物理删 T4-demo 打标 + operator_id=-1 夜审 + seed 置 20）
