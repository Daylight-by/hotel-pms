# 酒店管理 PMS 演示剧本（3 分钟版）

> 配套：`script/demo-start.sh`（一键启动/生成演示数据）、大屏「经营数据大屏」页右上角演示数据按钮。
> 数据源：T4 演示数据生成器（约 6 个月 400-600 笔订单，含淡旺季/周末峰/价格浮动），全部打标 `T4-demo`，可一键清理、不触碰验收数据。

## 1. 正式演示流程（3 分钟）

### 第 1 幕：经营数据大屏开场（0:00 - 0:20）

- 打开「经营数据大屏」页面（深色大屏，一屏四区）。
- 讲解点：
  - **左上**今日核心指标：出租率 OCC / 平均房价 ADR / RevPAR / 今日营收，均带「较昨日」环比箭头；
  - **右上**实时房态：按楼层展示 20 间房，绿=空闲、青=在住、黄=待清洁、红=维修，顶部图例带数量；
  - **左下**近 30 天经营趋势：营收柱 + 出租率折线，可看到 **7-8 月旺季明显高于 4-6 月、周末抬升**；
  - **右下**今日预抵/今日预离 + 待办提醒（待确认订单、今日应退房、待清洁房间、未结账订单）。
- 话术示例：「这是我们为中小酒店做的经营数据大屏，一屏看全今日经营、实时房态与近一月趋势。」

### 第 2 幕：小程序下单（0:20 - 1:00）

- 手机/开发者工具打开**酒店小程序**，进入「订房」：
  1. 选择入住日期（明天）、离店日期（后天）；
  2. 列表展示可订房型与价格（价格来自房价日历，旺季/周末价自动浮动）；
  3. 选择房型 → 填写入住人信息 → **提交订单并支付**；
- 回到管理端「订单管理」，**搜索刚下的订单**，状态为「已确认/待支付完成」，金额与小程序一致。
- 讲解点：小程序下单 → 订单实时进入 PMS 后台，渠道/房价计划联动。

### 第 3 幕：前台办理入住（1:00 - 1:30）

- 管理端订单详情 → 点击「**办理入住**」：
  - 订单状态：已确认 → **已入住**；
  - 房间房态自动置为「**已入住**」（大屏房态网格同步变青色）；
  - 系统自动开账，可立即记杂费。
- 刷新**大屏**：今日预抵 → 该客人变为「已到店」，今日营收 / 在住间夜上升。
- 讲解点：**入住即开账、房态联动大屏实时刷新**。

### 第 4 幕：账务入账 / 收款 / 冲销（1:30 - 2:00）

- 进入该订单**账页**：
  1. **入账**：记一笔「迷你吧」¥28（前台杂费）；
  2. **收款**：收一笔押金/房费（现金或微信）；
  3. **冲销**：对刚才的迷你吧明细做冲销（演示错误修正）。
- 打开「**操作审计**」页，按模块=账务筛选：
  - 能看到「入账」「收款」「冲销」三条记录；
  - 展开任意行：**beforeData / afterData** 完整记录变更前后 JSON。
- 讲解点：**所有敏感操作留痕、可追溯、可复核**，满足酒店内控与审计要求。

### 第 5 幕：夜审（2:00 - 2:30）

- 「夜审与营业日」→ 点击「**执行夜审**」：
  - 自动对在住订单过账当日房费（生成账务明细）；
  - 生成夜审记录，营业日 +1；
- 刷新「操作审计」：出现一条「**夜审**」记录；
- 刷新大屏：营业日变化，指标按新营业日展示。
- 讲解点：**日结闭环**——夜审过账 → 营业日推进 → 报表口径一致。

### 第 6 幕：报表收尾（2:30 - 3:00）

- 打开「**报表中心**」：
  1. **经营日报**：选择今天 → 展示 OCC / ADR / RevPAR（**满足 RevPAR = ADR × OCC**）、房费/其他/总营收、在住间夜、离店间夜、欠账余额、收款结构；
  2. **经营月报**：选择本月 → 逐日明细 + 当月汇总；
  3. 点击「**导出近 7 天日报**」→ 下载 xlsx，可现场打开展示（含营业日/出租率/ADR/RevPAR/各类收入列）。
- 讲解点：**日清日结、报表一键导出**，店长看得懂、财务对得上。

## 2. 备用话术（QA 环节）

| 可能被问到 | 回答要点 |
|-----------|---------|
| 数据怎么来的？ | T4 演示数据生成器：固定随机种子 6 个月 400-600 笔订单，淡旺季/周末峰/价格浮动，可一键清理，不污染验收数据 |
| RevPAR 怎么算的？ | RevPAR = 房费收入 / 可售间夜 = ADR × 出租率，口径与前台统计一致（房价日历 + 账务明细） |
| 操作审计记了什么？ | 入账/收款/冲销/改价/夜审/换房/入住/退房/取消订单，AOP 注解织入，记录 before/after JSON、操作人、IP |
| 大屏数据实时吗？ | 每次刷新实时查库；入住/夜审等操作后立即生效 |
| 演示数据会影响真实数据吗？ | 不会。全部打标 T4-demo，清理只删本包数据；验收脚本的数据不动 |
